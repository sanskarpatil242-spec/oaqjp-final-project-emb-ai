# Final Project

Emotion Detector web application using Watson NLP API and Flask.

## Description
This project was developed as the final project for the Coursera course: **Developing AI Applications with Python and Flask**.
It detects emotions (anger, disgust, fear, joy, sadness) from user text inputs and provides the dominant emotion.

## Technologies Used
- Python 3
- Flask
- Watson NLP Emotion Predict API
- Unittest
- Pylint

## Running the Application
```bash
python3 server.py
```

## Running Unit Tests
```bash
python3 -m unittest test_emotion_detection.py
```
